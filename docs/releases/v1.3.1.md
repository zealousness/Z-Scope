# Z-SCOPE v1.3.1

v1.3.1 是 C/C++ 稳定线。包内 `zscope._version.__version__` 为版本唯一真源，Git tag 必须为 `v1.3.1`。`zscope.candidate.v3.3`、`zscope.decision-context.v3.3` 等是内部 schema 版本。

## C/C++ 冻结基线

Linux/WSL 正式工具链、GLM-5.1、五次冷启动的冻结中位数：

| 指标 | 中位数 |
|---|---:|
| confirmed TP | 89 |
| raw FP | 2 |
| precision | 97.80% |
| with-review TP | 134 |
| with-review raw FP | 92 |
| needs-review | 135 |
| model tokens | 1,324,485 |
| wall time | 2,105.97 s |

硬门禁为 confirmed TP ≥85、precision ≥95%；with-review TP ≥134、raw FP ≤100、needs-review ≤150；tokens ≤6,000,000、wall time ≤3,600 秒；五轮全部完成并清空队列。原始运行作为 Release 资产；仓库仅保留摘要、参数、Git SHA、工具版本、哈希和复现命令。

## 交付变化

- Python 3.9–3.14 真实解释器 CI，Black/mypy 目标为 py39；离线包内置 CPython 3.13。
- C/C++ Joern 默认路径与离线包移除，1.x 兼容入口输出弃用警告。
- 新增 `--build-index`、`zscope-init`、`zscope-doctor`、`zscope-rules`、`zscope-maven-cache`。
- 新增签名校验的一键离线安装、语言拆包、SBOM、许可证、升级和回滚布局。
- Java Preview 代码按子系统选择性迁入，不合并 import 分支历史或其中的 Maven 仓库、私有镜像、密钥和无关功能。
- GitHub CI、secret/dependency scan、advisory AI review、人工批准 draft Release 和手工正式 benchmark 工作流落库。

## Java Preview 状态

结构基线为 58 条 truth（覆盖 49 个规则 ID）、54 个入口、48 条本地规则且 fixture 全覆盖。没有可信 LLM 指标；首次五轮正式基线发布前不声明 Java 精度。

## 回滚

离线安装使用 `releases/{version}` 与原子 `current` 链接；执行 `./install.sh --rollback 1.3.1` 可切换回已安装版本。候选/decision schema v3.3 缓存与更早 schema 不混用，报告 schema v2 保持可读。
