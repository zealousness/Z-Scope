02　流程怎么变了

准备并开始扫描

行为修复 + 交互

旧版

  1. 打开项目准备
  2. 跳转配置检查工程
  3. 回到准备页选择启动入口
  4. 快速检查可能忽略停止时间

新版

  1. 扫描任务中检查工程
  2. 确认模式、截止时间与时区
  3. 统一开始扫描

修复截止时间忽略问题应保留；步骤数量不代表完整用户耗时。

找到并复核问题

交互 + 视觉

旧版

  1. 集中验收筛选问题
  2. 跨页打开问题详情
  3. 在多个编辑区保存

新版

  1. 问题工作台筛选队列
  2. 同页查看证据
  3. 按复核、业务回答、处置分别保存

两栏更利于阅读；窄屏需要在列表和详情之间切换。

查看未完成范围

信息组织 + 正确性

旧版

  1. 在验收页查找编译实例
  2. 结合分散的覆盖与工具信息
  3. 区分零缺口与未测量

新版

  1. 打开覆盖与诊断
  2. 分别检查测量状态与缺口
  3. 定位未完成实例及原因

具体问题首屏更清晰；完整技术信息需要进入独立页面。
