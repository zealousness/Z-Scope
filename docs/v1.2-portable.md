# Z-SCOPE v1.2 Linux C/C++ portable

此包来自 `v1.2_feat` 维护分支，保留 v1.2 的业务流程和配置格式，并包含该分支回移的修复与性能改进。

## 使用

选择与机器匹配的 `x86_64` 或 `aarch64` 包，解压到任意可读目录。以下用 `$BUNDLE` 表示解压后的目录；路径可以包含空格。无需安装 Python、Clang、SVF 或 Node.js。

```bash
export BUNDLE=/path/to/zscope-1.2-linux-x86_64-cpp-portable
"$BUNDLE/bin/zscope" --help
cd /path/to/your/project
cp "$BUNDLE/examples/zscope.c_cpp.yaml" zscope.yaml
# 编辑模型、入口函数和工程路径；准备 compile_commands.json。
export OPENAI_API_KEY=your-key
"$BUNDLE/bin/zscope" -c zscope.yaml --build-cpg
"$BUNDLE/bin/zscope" -c zscope.yaml
"$BUNDLE/bin/zscope" -c zscope.yaml --dashboard
"$BUNDLE/bin/zscope" -c zscope.yaml --mcp-stdio
```

v1.2 仍使用 `project.root`、`project.source_root` 和平铺的 `indexing` 字段，不接受主线的新配置格式。模板的 `root: .` 相对于启动目录解析；从其他目录启动时应将其改为目标工程的绝对路径。工具通过包内启动器定位，模板不需要填写工具绝对路径。用户显式配置的工具路径仍优先。

默认 `unified` 后端组合 clangd/SQLite 索引和 SVF 分析。可以使用 `indexing.backend: clang` 只建立结构索引。本包不包含 Joern、Java 分析工具或主线新增的批量 Clang 前端；v1.2 的索引前端是 clangd LSP。使用 Joern 后端时需自行提供 Joern。

包内包含 Python 3.13、clangd 22.1.7、LLVM/Clang 18.1.0、SVF 3.2 的 WPA/Saber、gllvm、GCC、CMake、Ninja、Make、Git、证书及 WebUI 本地资源。LLVM 18 专用于 bitcode/SVF，clangd 22 用于索引。目标工程的第三方依赖、交叉编译工具链与模型服务由使用者提供。

## 兼容性与验证

工具在锁定的 Ubuntu 23.10 / glibc 2.38 容器内构建，运行时使用目标系统的 glibc。实际所需符号和实测系统下限分别记录在同名 `.abi.json` / `.abi.md` 与 `.smoke.json` 中，以这些随包报告为准。ARM64 在 QEMU 中验证，并在证据中注明。

离线验证使用普通用户、只读安装目录、含空格的工程路径和断网容器，覆盖启动、编译、bitcode、WPA/Saber、clangd、索引缓存、WebUI 本地资源、MCP 与报告导出。它验证发行包可运行，不替代业务准确率 benchmark，也不会调用模型服务。

本次产物为 `unsigned-local`，没有发布签名。下载后使用 `sha256sum -c SHA256SUMS` 校验。许可证位于包内 `LICENSE` 和 `licenses/`；SPDX 清单及产品/第三方对应源码作为独立交付文件提供。

## 重新构建

在 Linux/WSL 中使用 `scripts/portable_release.py`，工作目录放在 Linux 文件系统。构建依赖按 `requirements/portable/` 锁定，普通构建不更新依赖。

```bash
work="$HOME/.cache/zscope-v12-portable"
python3 scripts/portable_release.py bootstrap --work "$work" --profile cpp
python3 scripts/portable_release.py fetch --work "$work" --profile cpp
python3 scripts/portable_release.py build --work "$work" --profile cpp \
  --arm-compiler-helper --jobs 10 --output dist/portable-v1.2
python3 scripts/portable_release.py verify-package --work "$work" \
  --arch x86_64 --profile cpp --run-smoke --output dist/portable-v1.2
python3 scripts/portable_release.py verify-package --work "$work" \
  --arch aarch64 --profile cpp --run-smoke --output dist/portable-v1.2
```

单独构建一架构时添加 `--arch x86_64` 或 `--arch aarch64`。ARM 编译辅助工具仅用于构建，不进入发行包；目标探针、运行时和验证仍在 ARM 容器执行。打包基础设施来自主线 `2b483628008e`，按 v1.2 的入口、配置与 LSP 能力适配，没有引入 v1.3 分析架构。
