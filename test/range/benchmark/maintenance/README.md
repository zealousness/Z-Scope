# Range maintenance assets

Maintenance-only machine-readable data may live here. It is never copied into
benchmark scan input. Narrative mappings are maintained under
`docs/benchmark-maintenance/range/`.

`formal_verification_non_gt_audit.v1.json` freezes the 2026-10-23 independent
review of the externally supplied non-GT findings. It binds the source CSV,
probe details, fixture sources, final classifications, and the v17 truth
changes by SHA-256; it is maintenance evidence, not scanner input.
