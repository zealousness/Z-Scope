# Z-Scope LLM 交互效能与研判质量优化——实习期每周任务计划（2 Month）

本计划旨在围绕 **提升 AI SAST 漏洞检出能力并降低误报率** 这一课题，在不改变 Z-SCOPE 现有主体架构的基础上，优化 LLM 层面的交互与推理链路。目标在真实项目回测中将**误报率（FP Rate）降低 50%**，同时维持或略微优化扫描性能。
