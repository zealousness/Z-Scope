外部函数 配对函数 函数指针 函数意图 误报管理 CPG 管理
填写说明（点击展开）

当项目依赖的外部库函数无法获取源码实现时，需要在此手动描述其内存和并发行为，帮助 AI 理解函数语义。

  • 函数名 — 外部函数的完整名称，如 malloc、pthread_mutex_lock
  • 库名 — 所属库，如 libc、pthread、openssl
  • 描述 — 函数功能及其内存/并发行为，重点说明：是否分配/释放内存、是否返回指针、是否线程安全、对参数的约束等
  • 返回语义 — 返回值含义，如 成功返回 0，失败返回 -1 或 返回分配的内存指针，失败返回 NULL

提示：告警页面会显示分析过程中遇到的未知外部函数，可据此补充配置。

函数名库描述操作
填写说明（点击展开）

定义成对的资源获取/释放函数，用于检测资源泄漏、重复释放等问题。标准库函数（如 malloc/free）已内置，此处用于补充项目自定义的配对函数。

  • 类别 — 配对类型：memory（内存分配/释放）、lock（加锁/解锁）、refcount（引用计数增/减）、fd（文件描述符打开/关闭）
  • 获取函数 — 资源获取方，如 my_malloc、spin_lock、open_device
  • 释放函数 — 资源释放方，如 my_free、spin_unlock、close_device
  • 描述 — 简要说明配对关系，如 自定义内存池分配与释放
类别获取释放描述操作
填写说明（点击展开）

当 Joern 无法静态推断函数指针的指向时，需要用户手动指定。分析过程中遇到的未解析指针会在告警页面提示。

  • 指针位置 — 函数指针的声明位置，如 device_ops.read（结构体成员）、g_callback（全局变量）、handler_fn（局部变量）
  • 范围 — local（函数内局部指向）、global（全局变量指向）、ignore（标记为可忽略，不影响分析结果）
  • 目标函数 — 该指针可能指向的具体函数名，多个用英文逗号分隔，如 read_impl_v1, read_impl_v2

提示：选择 ignore 表示该指针指向不影响缺陷检测，分析时将跳过相关路径。

位置范围目标操作
填写说明（点击展开）

描述函数的设计意图和并发关系，帮助 AI 判断是否存在数据竞争等并发问题。

  • 函数名 — 需要标注意图的函数名，如 process_request
  • 并发组 — 该函数所属的并发分组标识，同组函数不会并发执行。如 io_thread、timer_task、main_loop
  • 并发对象 — 与本函数存在并发执行关系的其他并发组名，多个用英文逗号分隔，如 network_layer, cache_layer
  • 备注 — 补充说明函数对调用者的约束，如 调用前必须持有 g_mutex 锁、传入指针保证非 NULL

提示：并发组用于建模任务/线程间的并发关系。同一并发组内的函数被视为串行执行，不同组之间根据"并发对象"字段判断是否存在并发。
