# Z-Scope LLM 交互效能与研判质量优化——通过工具调用、Skill 路由、上下文治理与领域知识注入，提升 AI SAST 漏洞检出能力并降低误报率。

> 总目标：在不改变 Z-Scope 主体架构的前提下，优化 LLM 层的交互链路，使模型更少走弯路、更准确地使用工具、更聚焦地使用 Skill、更充分地利用领域知识，最终提升漏洞挖掘有效性并降低误报。在真实项目回测中，**假正率降低 50%**，且性能维持不变或略微优化。

---

## 参考方向

1. **工具调用**：降低无效/重复工具调用，提升一次调用命中有效证据的比例。
2. **Skill 使用**：让不同漏洞类型自动匹配合适 Skill，避免全量 Skill 造成上下文噪声。
3. **上下文管理**：控制 Token 成本，保证 Source/Sink、路径、调用关系、正反证据等价值信息优先进入上下文，优化上下文内容和结构。
4. **领域知识**：将项目 API 语义、外部函数、成对资源、函数意图、历史误报沉淀为可注入知识，优化当前 LLM 自动提取领域知识的能力。
5. **前置信息收集优化**：当前函数入口发现、`custom_prompt` 生成实现比较粗糙，依赖正则或者固定规则，造成一些错误接口被识别。

---

## 评估手段

### 1. 基于当前版本开展基线评测与问题画像，定义并关注指标：

* **交互效率**：固定模型单入口平均toolcall次数、重复工具调用次数、平均上下文token、累计 prompt token、单入口耗时。
* **工具质量**：工具调用成功率、参数错误率、无效工具调用率、被loop guard截次数。
* **上下文质量**：有效证据覆盖率、Source/Sink 是否进入上下文、正反证据是否完整，是否有重复证据。
* **漏洞效果**：Recall、Precision、F1、误报率、`needs_review` 比例。
* **成本指标**：每个confirmed finding 的 token 成本、每个误报的token成本。
